| 内容 | 本次状态与用途 |
| --- | --- |
| 数学推导与verify_math.py | 公开；NumPy即可复算 |
| 九场景冻结几何特征、927条扰动结果与汇总 | 按本轮结果发布要求导出；无本地绝对路径或患者资料 |

| 三个源CAD、场景、材质、RGB及Oracle Mask文件 | 未上传；不提供虚构下载地址 |
| 真实790帧完整数据、视频、分割权重 | 原有范围不变，本轮不新增公开 |

源模型分别为Ip4（原始BLEND）及从既有源模型压缩包核验恢复的Is14、IIa6.5。文件SHA256已核对；维护者于本轮明确确认三模型及沿用材质的来源与许可，允许公开派生图，不公开模型原文件。许可范围记录于[DISTRIBUTION_APPROVAL.json](DISTRIBUTION_APPROVAL.json)。公开数值表只描述冻结测量特征，不包含完整网格。

当前完整虚拟场景端到端重算仍需这些原始资产及相同环境。对外已提供的是**数学与数值结果复算**；不得据此声称已经公开原始场景端到端复现。尚未纳入公开的素材清单见[PENDING_ASSETS.json](PENDING_ASSETS.json)。
